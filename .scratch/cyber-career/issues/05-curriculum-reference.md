# What a cybersecurity degree actually covers — the standard body of knowledge

Type: research
Status: open
Blocked by: none

## Question

Establish the reference curriculum so the owner's own syllabus can be measured against it: the ACM/IEEE
CSEC2017 knowledge areas (and any 2025+ revision), plus what accredited cybersecurity bachelor's programmes
in practice require.

For each knowledge area: what it is, what a student is expected to be able to do at graduation, and which
certificate or free resource covers the same ground. The output is a crosswalk skeleton: knowledge area →
course topics → certificate overlap → practice platform.

Also name the free/practical training grounds that cost a Bangladeshi student nothing or close to it
(TryHackMe, Hack The Box, LetsDefend, PortSwigger Web Security Academy, Blue Team Labs Online, OverTheWire,
picoCTF, range/VM labs), with what each is actually good for and its real price in BDT terms.
